# 🎮 NoKakulaLeveling

Браузерное расширение для Twitch: **скрывает Какула Левелинг из чата** и добавляет **быстрые команды с автодополнением** прямо в поле ввода.

## ✨ Возможности

### 🚫 Фильтрация чата
- **Скрытие чужого Какула Левелинга:** одним тумблером — со ссылкой на ваш ник, чтобы не скрывать сообщения с упоминанием вас.
- **Универсальность:** работает одинаково хорошо как на **прямых трансляциях (Live)**, так и на **записях стримов (VOD)**.
- **Мгновенная работа:** фильтрация в реальном времени без задержек и нагрузки на браузер.

### ⚡ Быстрые команды (новое!)
- **Всплывающие подсказки** прямо над полем ввода чата — до 5 лучших совпадений, отсортированных по категориям:
  - 🧱 **«Это база, это знать надо»** — базовые команды
  - ☕ **«Какула Левелинг»** — команды для Какула Левелинга
  - 🛡️ **«Какула Дефенс»** — команды для новой игры
- **Выбор подсказки мышью или клавишей Tab.**
- **Идеальная вставка текста в поле ввода** — порт метода [SevenTV Extension](https://github.com/SevenTV/Extension/)

### 🔒 Приватность
Расширение работает полностью локально в вашем браузере. Оно не собирает, не хранит и не передаёт никакие личные данные на сторонние серверы.

### 🔄 Проверка обновлений
Кнопка «Проверить обновление» в попапе сравнивает версию с GitHub Releases.

## 📂 Как это устроено

| Файл | Назначение |
|---|---|
| `manifest.json` | MV3-манифест: content-скрипты в isolated и MAIN worlds |
| `filter.js` | Логика скрытия сообщений (паттерны из `patterns.json`) |
| `content.js` | MutationObserver за чатом Twitch, применяет фильтр |
| `chat-input.js` | Панель подсказок быстрых команд + мост к MAIN world |
| `page-world.js` | Порт SevenTV: поиск Slate-редактора через React Fiber и вставка текста операциями Slate |
| `popup.html / popup.js` | Настройки: тумблеры, ник, проверка обновлений |
| `patterns.json` | Списки команд по категориям (легко дополнять!) |

## 📥 Установка

### Способ 1: Из релиза (рекомендуется)

1. Перейди в раздел **[Releases](https://github.com/SubaKon/NoKakulaLeveling/releases)** и скачай последний ZIP-архив
2. **Распакуй** архив в любую папку на компьютере
3. Открой браузер (Chrome, Яндекс, Edge, Opera) и введи в адресной строке: `chrome://extensions`
4. В правом верхнем углу **включи переключатель «Режим разработчика»**
5. Нажми кнопку **«Загрузить распакованное расширение»** (слева вверху)
6. Выбери папку, куда ты распаковал архив
7. Готово! Нажми на иконку расширения (пазл 🧩 вверху справа браузера) и включи нужные тумблеры

### Способ 2: Из исходного кода (больше фич, больше багов)

1. Нажми зелёную кнопку **Code** → **Download ZIP**
2. Распакуй архив
3. Открой браузер (Chrome, Яндекс, Edge, Opera) и введи в адресной строке: `chrome://extensions`
4. В правом верхнем углу **включи переключатель «Режим разработчика»**
5. Нажми кнопку **«Загрузить распакованное расширение»** (слева вверху)
6. Выбери папку, куда ты распаковал архив
7. Готово! Нажми на иконку расширения (пазл 🧩 вверху справа браузера) и включи нужные тумблеры
8. Молись что баги будут незначительные


## 🚀 Использование

1. Кликни по иконке расширения в панели браузера
2. Включи нужные тумблеры:
   - **Скрыть чужой Какула Левелинг** — фильтрация чата
   - **Ваш Twitch ник** — чтобы не скрывать сообщения с упоминанием вас
   - **Быстрые команды** — подсказки в поле ввода (+ мини-тумблеры категорий)
3. Печатай в поле ввода чата — появятся подсказки. Выбирай мышью или жми **Tab**
4. Наслаждайся чистым чатом! ✨
